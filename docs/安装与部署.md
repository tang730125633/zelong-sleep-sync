# 安装与部署

目标：先手动跑通，再绑定微信
不要在手动上传失败时直接调自动化

## 1 · 启动自己的服务

Python 3.10+，仅使用标准库

```sh
python3 test_bridge.py
python3 test_http.py
HEALTH_DATA_DIR=/你自己的私有目录 python3 server/app.py --port 8768
```

省略 `HEALTH_DATA_DIR` 时，使用当前目录下的 `data/`
服务为单用户设计，不包含注册或登录页面
终端退出会停止服务，长期运行需交给自己的进程管理工具

首次启动生成 `upload.key` 和 `read.key`
两者不可相同，不要放入公开网页或 Git
数据目录、数据库与密钥都留在服务器私有路径
已有密钥权限过宽时，服务会拒绝启动

## 2 · 提供 HTTPS 入口

先让自己的域名指向服务器，配置有效 TLS 证书
独立服务只监听本机，不应把 8768 端口直接对外开放

已有 HTTPS Nginx 站点中，可以添加类似配置

```nginx
# 在已有的 HTTPS server {} 中
location /api/health {
    client_max_body_size 4m;
    proxy_pass http://127.0.0.1:8768;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_read_timeout 30s;
}
```

这个片段不负责申请证书
也不要覆盖同一域名下已有的业务接口
公网入口应按自己的环境设置请求限流
应用不记录健康正文和密钥，代理日志也不应记录它们

## 3 · 在 Mac 生成快捷指令

```sh
python3 build_shortcuts.py \
  --endpoint https://你的域名/api/health/import

shortcuts sign --mode anyone \
  --input dist/睡眠同步.unsigned.shortcut \
  --output dist/睡眠同步.shortcut
```

构建文件不含密钥
默认只生成近两天的睡眠同步版本

签名需要 macOS 自带的 `shortcuts` 命令
将签名后的 `.shortcut` 文件传到自己的 iPhone
可使用隔空投送，收到后确认导入完成
“已发送”不代表手机已经安装

## 4 · 手机上先手动运行

1. 导入时填写自己服务器的 `upload.key`
2. 允许读取睡眠，允许连接自己的域名
3. 保持手机解锁，运行「睡眠同步」
4. 等待服务器返回 `imported` 和 `changed`
5. 再用读取接口或 MCP 核对日期

密钥不要填写到 Safari 搜索栏
镜像输入可能取到 Mac 的旧剪贴板，填写后核对来源
原生健康动作必须在 iPhone 上验证，Mac 运行不能替代真机验收

## 5 · 绑定打开微信

在 iPhone「快捷指令」中：

1. 打开「自动化」
2. 创建或编辑「App」触发条件
3. 选择微信，勾选「被打开」
4. 选择「立即运行」
5. 执行「睡眠同步」
6. 手动打开一次微信

若出现健康数据分享询问，检查目的地是自己的域名
愿意长期自动上传时，再自行选择「始终允许」
原项目已经完成该授权，并验证再次打开微信能上传

不要保留多个重复的微信触发规则
已有旧导出自动化时，替换它的执行对象即可

## 6 · 验收，而不是只看界面

- 未带读取凭证查询：应返回 401
- 上传凭证不能读取数据
- 读取凭证不能上传数据
- 手机上传后：返回成功回执
- 再次上传同一批：`changed` 应为 0
- 读取接口与 MCP：日期和结果一致
- 修改错误样本后上传：拒绝整批，不破坏旧睡眠记录

独立版的 `test_http.py` 覆盖以上关键接口路径
其中全部使用合成记录，不能代替你自己手机的最终验收

## 排查顺序

| 现象 | 先查哪里 |
| --- | --- |
| 微信打开，没有回执 | 自动化是否启用、是否有待确认权限、网络是否正常 |
| 401 | 上传与读取密钥是否混用 |
| 400 / invalid_source_data | 手机读取权限、样本是否为空、时间格式与分期标签 |
| 413 | 样本或正文过大，缩小时间窗口 |
| `changed: 0` | 通常是重复数据，继续查询日期确认 |
| 服务端没有新请求 | 排查手机触发或网络，不要先修改数据库 |
| 历史补传被 iOS 阻止 | 缩小日期窗口，逐批完成 |

代码不会无限重试，也不会凭空补齐健康记录
恢复网络后，可以再次手动运行或重新打开微信
